# Модуль учета заявок в службу поддержки (Тикет-система)

## Описание проекта
Информационная система для автоматизации процесса учёта, маршрутизации и обработки обращений пользователей в службу поддержки организации.

## Используемые технологии
- Язык программирования: Python 3.10+
- СУБД: Microsoft SQL Server
- Графический интерфейс: Tkinter
- Система контроля версий: Git + GitHub
- Планирование задач: Trello (Kanban-доска)

## Установка и запуск
1. Клонируйте репозиторий: `git clone [URL репозитория]`
2. Установите зависимости: `pip install -r requirements.txt`
3. Настройте подключение к БД в файле `src/db_config.py`
4. Запустите приложение: `python src/main.py`
