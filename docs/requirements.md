# Нефункциональные требования

## 1. Производительность
- Время отклика системы при создании заявки: не более 2 секунд
- Поддержка одновременной работы до 100 пользователей
- Время формирования отчёта: не более 5 секунд

## 2. Безопасность
- Пароли хранятся в хешированном виде (SHA-256)
- Разграничение доступа по ролям (RBAC)
- Защита от SQL-инъекций через параметризованные запросы

## 3. Надёжность
- Резервное копирование БД ежедневно
- SLA доступности системы: 99%

## 4. Масштабируемость
- Модульная архитектура (MVC)
- Возможность добавления новых категорий и статусов без изменения кода
